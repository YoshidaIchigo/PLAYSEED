# 参照ステージの地形

参照動画: https://www.youtube.com/watch?v=y9ho_afrkrY

現行の独自の円柱山と平面を置き換えるための地形単位です。UI単位PR46の後に分けて実装します。敵・砲台・収集物の再配置前なので、この単位では明示的な開発オプション `-ReferenceCourse` から新地形を起動します。通常の入口への統合は次の単位です。

地形の輪郭と通路の寸法・接続を推測で決めないため、公開されている位置・面の一次資料を参照しました。

- 描画形状・UV区分: https://github.com/n64decomp/sm64/tree/master/levels/bob/areas/1
- 歩行面・壁・木17本: https://github.com/n64decomp/sm64/blob/master/levels/bob/areas/1/collision.inc.c
- 開始点・山頂・各機構: https://github.com/n64decomp/sm64/blob/master/levels/bob/script.c
- 山道を通る順路: https://github.com/n64decomp/sm64/blob/master/levels/bob/areas/1/trajectory.inc.c

座標は元の `(X,Y,Z)` をUEの `(X,-Z,Y)` へ回転し、1単位を1cmとして扱います。開始点は `(-6558,-6464)`、山頂の歩行面は約4294cm、浮島の上面は3072cmです。描画1101三角形と衝突1060三角形を別Componentに持ちます。見た目の装飾の隙間が歩行面を変えません。Collisionの同期待ちを有効にし、生成後のR復帰で未生成の床に落ちることを避けます。

テクスチャは草・土・石・木・柵・空を数式と固定乱数で新しく描いたものです。元の画像、音、ROMは含めていません。描画の区分に公開資料の形状を用いていますが、画像のピクセルやUEでの照明まで同一とは主張していません。

`ThunderReferenceTest` は新規の専用セーブを要求し、実ゲームで入力とCharacterMovementの通常の歩行・ジャンプを使って開始地点から木橋と山道を通り山頂まで進みます。座標・速度・体力・報酬の注入は行いません。最後にRとMを通し、専用セーブにもスターを書き込まないことを確認します。通常のセーブとユーザーが開いているエディターを保持します。

実際の経路検証では、参照NPC用の折れ線をそのまま徒歩の線と見なさず、衝突三角形上の足元と壁の余裕から経路を計画します。山道の約3.4mの切れ目は通常Jumpで渡します。足元を計画してもゲーム内のプレイヤー座標は設定せず、歩行・ジャンプ・着地を実測して合否を決めます。
