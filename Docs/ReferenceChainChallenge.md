# 参照位置の杭・ワンワン・鉄格子

参照プレビューへ、杭、黒い球状のワンワン、金属球4個の鎖、鉄格子、その奥に最初から見えるスター6を追加します。地形と同じ座標変換 `(X,Y,Z) → (X,-Z,Y)` を使います。

|対象|UE座標 cm|補足|
|---|---|---|
|杭の基準|260, -1920, 735|地面は768付近。自作の杭は225cm、1回65cm沈む設定で3回目に解放|
|鉄格子の基準|1456, -446, 768|自作の格子は中央を原点に持つため、Actor中心は高さを200加えた968|
|スター6|1550, -300, 1200|入場時から格子の奥に表示。格子を壊すだけでは獲得しない|

黒い本体、口、歯、目、鎖と影は同梱形状と自作素材で構成しています。モデルと移動アニメーションは独自実装です。鎖の範囲900cm、ダメージ3、見える金属球4個と解放後の4回の跳ねる動きは参照資料に合わせています。通常版の既存Actorとは設定を分け、参照プレビューのときだけ使用します。

位置の根拠は[Bob-omb Battlefield配置](https://github.com/n64decomp/sm64/blob/master/levels/bob/script.c)と[マクロ配置](https://github.com/n64decomp/sm64/blob/master/levels/bob/areas/1/macro.inc.c)、仕組みの確認には[Chain Chomp behavior](https://github.com/n64decomp/sm64/blob/master/src/game/behaviors/chain_chomp.inc.c)を使用しました。ROM、元の画像、音声は使用していません。

この単位の実動作検証は、絵への入場から通常の歩行とジャンプで杭へ進み、3回のヒップドロップ、解放された敵の実際のSweepによる格子破壊、奥のスターの表示を確認して、取得前にMで入口へ戻ります。QAからプレイヤーの座標・速度・体力・報酬を設定しません。スター取得時のポーズ・カメラ・保存失敗対策・全スターの自動帰還は、次の独立した単位で接続します。
