# 絵入場と帰還の白フェード

参照: [指定動画](https://www.youtube.com/watch?v=y9ho_afrkrY)。匿名で取得した公開動画を0.25秒刻みで復号して確認しました。動画全体は開発用の一時フォルダだけに保存し、ゲーム素材には使いません。

- 01:30.25〜01:31.25頃：絵の接写から、4:3の画面全体が白い矩形で徐々に覆われます。円やスター形のマスクはこの箇所にはありません。選択画面も白背景から現れます。
- 01:35.00〜01:36.75頃：選択画面が白く消え、白を保ってからコースの空中入場が明転します。
- 03:47〜03:50頃：スター取得のポーズと表示を確認。この公開動画では03:50に選択画面へ戻り、その後再びコースへ入る挙動です。ユーザー指定の戻り先は絵の前なので、その指定を優先します。

実装値は白矩形のフェードアウト1.00秒、次Worldのカメラ・HUD準備後に完全な白を0.15秒以上保持、フェードイン0.75秒です。絵へ飛び込む2秒の演出と、スター取得ポーズ2.4秒の後につなぎます。参照の時刻は動画からの概測で、実装値を計測値そのものとは扱いません。

白の不透明度はGameInstanceに保持し、完全な白で一度だけOpenLevelします。入口・選択・コースのHUDの最前面へ同じ不透明度を描くため、切替直後に旧場面や新カメラが一瞬見える経路を防ぎます。新WorldのHUDとController（入口/コースではPawnも）が準備されるまで明転を始めません。明転中も入力を止め、コースでは明転と実際の着地の両方を終えてから操作を戻します。

検証は新規の隔離セーブを使い、絵→選択→降下→M帰還→再入場→再降下→実スター6取得→絵帰還→再入場、計7回のフェードを通常操作で通ります。全7回で白化・完全被覆・明転・完了を監視し、遷移中の連打と選択表示の不変性を確認します。動画の実画素も確認します。
