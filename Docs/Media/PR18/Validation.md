# PR #18 実ゲーム検証

対象コード: b1c8a838e5f5d99da377f74b50a8f923fafcf316

- Character所有のCarry ComponentがE/Xの入力と保持を管理し、持てる物Actorが見た目・衝突・投擲・着地を担当する。
- 170cm以内の専用Actorだけを対象にする。保持中は物の物理と衝突を止め、物だけをCharacterへAttachする。プレイヤー自身の移動方法は変えない。
- 投げるときはDetachし、物理移動へ戻して前向きの速度と上向きの速度を与える。CCDで高速時の床抜けを抑え、物理衝突から投擲の着地を一度だけ観察する。
- 放した直後はPawnとの衝突を短時間除外して自分への引っ掛かりを避ける。被弾・ヒップドロップで手放し、R・死亡では物を元の位置へ戻す。物と保持側は弱参照で寿命を延ばさない。
- 検証は遠い物の拒否、Eで保持、通常歩行での追従、物理投擲と着地、Rでの位置初期化、Xでの再保持、実際のイバラ接触での解除、再保持したままの場外復帰を確認する。
- 場外への座標置換は復帰時の保持解除だけに使用する。持ち上げ・運搬・投擲は通常入力と物理移動で行う。既存Gardenの全6種収集・ゴール・Rも回帰確認する。
- 日本語コメントでActor/Componentの所有、入力、UPROPERTY、弱参照、物だけのAttach、投擲の物理、着地一回と状態初期化を説明した。保存形式は変更していない。
- 動画は実ゲームの自動操作で、人が入力機器を操作した手動検証ではない。

- 最初の試行では画像保存直後の1フレームを壁時計0.3秒として飛距離判定し失敗した。解除・物理状態の確認を維持し、実着地を待って200cm以上の飛距離を確認する検証へ修正した。再実行では1087.5cmの物理飛行と一度だけの着地を確認した。
