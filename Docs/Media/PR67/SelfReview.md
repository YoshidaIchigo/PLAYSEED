# 落下水玉のセルフレビュー

- 各出現元は自分の水玉1個、影、光、飛沫5個を所有します。全ComponentをActorとUPROPERTYで保持し、入場のWorldと一緒に破棄されます。
- 元の3地点はUE(3620,-4800,4000)、(-5141,743,3764)、(-4208,2036,3769)。範囲はパラメータ15/25/10から950/1450/700cmです。実プレイヤーの位置と速さから少し先を狙い、出現元の高さ+2000から落下します。
- 実床の影、Worldへの球スイープ、実カプセルとの最近接で接触を判定します。通常のVitality窓口へ1ダメージを依頼し、押し戻しや無敵時間も既存の仕組みを使います。QAが座標・速度・体力・進行を変更する経路はありません。
- 水玉は床で潰れ、2回跳ねてから飛沫になります。接触時は通知より先に水玉を終了し、Revisionが死亡/R初期化後の古い状態の上書きを防ぎます。Rは自分の水玉/影/飛沫を隠し、診断用の累計だけを保持します。
- 材料は既存の自作M_ActorとUEの基本形状。元のゲームの画像、音、モデルは取り込んでいません。
- 3地点の範囲を実Worldで確認し、実接触した地点を記録して、R後にその同じ地点の次の水玉を普通に避けます。別地点の被弾も合計回数と実HPで検出し、Rで隠さないよう回避後にも確認します。
