# 鉄球のセルフレビュー

- 各ActorはWorldが所有し、StageはFieldをUPROPERTYで保持します。Fieldも鉄球への参照を保持し、入場を終えた際はWorldと一緒に破棄されます。
- 山道は公開された18/27点の数値経路を座標変換し、実地形だけへのトレースで足元へ合わせます。半径100、2ダメージ、下りで600から最大2100cm/sへ加速する自作の処理です。素材、球と反射の形は自作です。
- くぼ地は元配置の3か所を中心に実床に沿う半径180cmの連続周回です。元ゲームの物理計算そのものの移植ではありません。目的1は2個、目的2以降は3個です。
- 接触は既存の線分と実カプセルの最近接判定から、Vitalityの通常の窓口へ依頼します。無敵時間と押し戻しも既存処理を使います。位置・速度・体力・報酬をQAから直接設定しません。
- 致命傷やRで同じTick中に再開されても、MotionRevisionが古い位置の書き戻しを防ぎます。Rで全鉄球の経路/速さ/回転を初期化し、診断用の接触累計だけは保持します。
- 正当に全7個を実取得済みの専用セーブを引き継ぎ、目的6から通常の入場/落下/歩行で実接触し、HP8→6と押し戻し、RでHP8/入口/全5個を2回確認します。セーブのコピー、直接進行設定、体力注入はしません。
- 最初のEditor7437でTObjectPtrをauto*へ推論する1か所のビルドエラーを発見し、明示的なActorポインタへ修正しました。Editor7438/Game Developmentの両ビルドは成功しました。

実動作Bは1544フレーム、UTC2026-10-16T16:25:18.585ZでPASSしました。くぼ地の実接触→HP6→R、山道上側の鉄球0との実接触→HP6→R→Mで絵前帰還。山道の2個はそれぞれ6/5周を実完走しました。最初のAは下側だけを想定した検証で上側の実接触を失敗としていたため、両者の接触元を照合する判定へ修正し、Editor7439/Gameの両ビルドを再度成功させています。全編MP4を直接復号して確認する工程はこれから行います。
