- 3列は元のローカルZを160cm間隔で5枚、yawを回してUEの(X,-Z,Y)へ変換する。8枚の輪は参照位置を中心に半径300cm。実地形Componentの床を探してコイン中心を30cm上へ置き、床が見つからない配置は警告して検証を失敗させる。
- 一次資料の木の杭の条件は400cm以内、同じ向きの累積角度が3周を超え、200フレーム未満。30Hzから200/30秒へ換算する。時間超過なら実際に外へ歩いてからやり直す。QAは角度・タイマー・生成を設定しない。
- 杭の報酬は生成済みを先に確定し、5枚の固有IDを一度だけ作る。ヒップドロップで沈んだ後は周回報酬を出さない。Rではその杭自身のドロップだけを破棄し、周回と沈みを初期化する。
- 木箱は既存の通常攻撃/ヒップドロップ・3枚生成・重複防止を継承し、木の素材へ合わせる。通常セーブや既存進行を直接変更しない。
- コースのR復元へCoinFieldを追加する。Fieldが追跡する静的23枚、4杭のドロップ、箱の内容物だけを戻す。
